Most reliable iPhone setup
  1. Tap Copy secure calendar URL above.
  2. Open Settings → Apps → Calendar → Calendar Accounts.
  3. Tap Add Account → Other → Add Subscribed Calendar.
  4. Paste the URL and tap Next, then Save.
Google Calendar or Outlook

Use your calendar's Subscribe from URL or Add calendar from internet option and paste the secure URL.
